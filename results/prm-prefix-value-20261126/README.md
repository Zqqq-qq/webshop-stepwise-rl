## 一、机制诊断与三项改进设计

1. **消除轨迹求和共线性捷径（`stage126` $\to$ `Arm 1`）**：
   - 原目标 $(\sum_{t=0}^{T-1} s_t - R)^2$ 用单个标量约束 $T$ 个未知回合分；由于点击步仅含小写编号 `click[b07yngtfk3]`，而后续详情页直接展示商品标题，梯度下降倾向在点击步输出位置常数（`~0.25`）并将区分度推迟至末步。
   - **前缀价值回归 + 望远镜差分**：令线性头在每个助手回合末 `<|im_end|>` 预测前缀条件期望 $\hat{V}_t \approx \mathbb{E}[R \mid h_t]$，训练损失改为逐步独立蒙特卡洛 MSE：
     $$\mathcal{L}_{\text{PV}} = \frac{1}{T} \sum_{t=0}^{T-1} \big(\hat{V}_t - R\big)^2$$
     推理与步级奖励输出相邻差分 $s_0 = \hat{V}_0,\; s_t = \hat{V}_t - \hat{V}_{t-1}$（严格满足 $\sum_{t=0}^{T-1} s_t \equiv \hat{V}_{T-1}$）。当点击前页面证据充足时，$\hat{V}_t$ 必须在点击当步拉开以降低当步误差；当关键规格点进详情页才出现时，MSE 最优解自动在点击步给出中性条件期望，将跳变留给详情页出现后的下一步。
2. **补齐跨位置键匹配与 MLP 容量（`Arm 1` $\to$ `Arm 2`，原文零改动）**：
   - 将 PRM LoRA `target_modules` 从 `('q_proj', 'v_proj')` 扩展至全部 7 个线性层 `('q_proj', 'k_proj', 'v_proj', 'o_proj', 'gate_proj', 'up_proj', 'down_proj')`（`r=8, alpha=16`，RTX 3090 FP32 峰值显存 `6.94 ~ 7.08 GiB`）。
3. **消除搜索页大写 ASIN 与动作小写 ASIN 的 BPE 断层（`Arm 2` $\to$ `Arm 4`，零特权回填）**：
   - 搜索页展示全大写 `B07YNGTFK3 [SEP] Title [SEP] $Price`，而动作输出全小写 `click[b07yngtfk3]`（Qwen BPE 字母 token 重合数为 `0`）。`Arm 4` 在 PRM 评分编码时，仅通过确定性正则从紧邻上一条用户已见观察 `messages[i-1]` 中提取该 ASIN 的公开标题与价格片段附于评分视图（超 `2048` 自动回退原文，保留样本集与基线 `100%` 相同）。
