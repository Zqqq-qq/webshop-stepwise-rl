## 3. 学习率短程观测

评分头是「151936维词表logits → 线性 → 逐回合求和」的聚合。下列三次均为FP32，每次仅5步，且每步换样本；只能描述这些短程观测：

| lr | totals 序列（5 步） | 结果 |
|---|---|---|
| 5e-6（上游默认） | 0 → 6.77 → 19.42 → 3.79 → 0.02 | 本次短程loss尖峰约377 |
| 1e-6 | 0 → 1.36 → 3.89 → 0.76 → 0.004 | 本次短程loss尖峰约15 |
| 1e-7 | 0 → 0.135 → 0.815 → 0.31 → 0.376 | 本次短程尖峰较小，不构成长期稳定性证明 |

1e-7的loss实际为`1 → 0.28218248 → 0.66423947 → 0.19378026 → 0.08469537`，并非单调递减；其他两组尖峰后也有下降，不据此断言持续发散。

撤回“bf16下更新几乎不动，因此FP32必须降低学习率”的因果结论。当前没有同初始化、同样本顺序、同优化器的bf16/FP32对照；精度和最优学习率的关系仍为待验证假设。本次修正措辞不要求额外GPU实验，如未来提出因果结论再另做受控实验。评分定义未改。
