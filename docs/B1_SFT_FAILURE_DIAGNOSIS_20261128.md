# B1 丢分与 SFT 错误诊断

## 输入与口径

采用同一 val160 的已验收 B0/B1 FP32 贪心轨迹。B1 rollout SHA-256 为 `a8036105692bef6c60ce3eff54492490dfe74c5d8bfb112c314e684bee4568d3`。未购买按终局 0 计，满分须完成购买且得分至少为 1−1e−6。商品页上的中间分仅供定位，丢分归因使用动作、商品标题、价格和已选规格判断。原始轨迹只保留环境总分，无法逐题复原评分器的类目、属性、规格和价格子分。

B1 的 106 道未满分题中，102 道已经购买。部分分题中，13/98 曾出现无效动作，85/98 的动作全可执行。全量 156 笔购买中，151 笔同时可解析预算和购买前页面的 Price 字段，其中 14 笔页面最低显示价高于预算（部分分 11、零分 3），2 笔价格区间跨预算。区间跨线的题保留为不确定。页面价格是可见证据，不能替代最终成交价格或环境子分。部分分购买中，有 63/98 在购买时记录的 selected_options 为空。没有显式选择的任务可能不要求规格，因此这 63 道不能统计为漏选。

在这批日志里，156 笔完成购买的轨迹均未执行成功的 Description、Features 或 Reviews 跳转。该现象只描述本批策略行为，不能推断所有题都需要这些页面。4 道未购买都耗尽动作上限，合计 27/40 回合无效。

## SFT 判读与后续验证

本轮 SFT 以专家助手回复作 token 级监督。执行记录表明 B1 学会了多数动作格式与购买流程。现有材料可以识别行为错误，不能证明训练集缺少某类示范，也不能仅凭验证 loss 或单次训练确定 LoRA 容量和轮数是否足够。下一步先在训练池统计多约束规格决策、规格拼写映射、超预算拒买、重新搜索和无效动作恢复的示范覆盖。如果覆盖薄弱，从训练池补足这些决策点的正确示范，并保留普通轨迹作对照。优先级为购买前多约束检查、商品类型与预算筛选、导航恢复。保留现有 B1 供当前 PPO 对照。

候选 SFT 与 B1 用同底模、同精度和生成预算在未参与诊断或训练的新留出上做逐题配对比较。主指标为满分购买，并记录购买率、规格遗漏、明确超预算购买和无效动作率，同时检查部分分向满分的转化。已查看的 val160 题仅用作回归诊断，纠错样本从训练池选取。test200 保持冻结。

## 待评审的最小实验方案

1. **先查训练覆盖。** 从既有训练池抽取选品、规格、预算和导航恢复片段。逐条记录任务 ID、用户约束、动作前可见证据、专家动作与终局标签。验证题仅用于描述错误类型。对于页面证据不足的样本，先复核或补采，再决定能否作为监督。
2. **固定一个候选与可比对照。** 若训练覆盖确有缺口，先只改示范构成，保留普通购物示范，补多约束商品选择、规格确认和可执行的恢复动作。预先锁定底模、LoRA 目标模块、训练预算和种子。若资源允许，以同预算的原数据训练作为对照，区分数据构成与额外训练带来的影响。
3. **冻结验收口径后再训练。** 在未查看、未参与训练的新留出任务上用相同 FP32 评估配置逐题对照。报告满分购买率的配对差和区间，同时披露购买率、规格遗漏、可确认超预算购买和非法动作率的计数及分母。排期和最低可接受改善幅度由组内评审确定。

请评审训练覆盖的抽样范围、最先补哪类示范，以及同预算对照与独立验证的可执行性。当前 B1 继续作为已冻结的 PPO 起点。
